# paper_prymetime_genomes

Engineered genome assemblies (FEY_* strains) generated by Prymetime, plus three reference genomes
(K. phaffii, S. cerevisiae, Y. lipolytica), as FASTA files. Data for the paper at https://doi.org/10.1101/2020.05.05.079368.

## For whom
- The `FEY_*_final.fasta` assemblies and the three reference FASTAs: readers of the paper, from the GitHub repo. Public data, no code.

## Where
- Runs on: nothing runs; it is a data-only repo, hosted on GitHub (emyounglab).
- Data: the FASTA files at the repo root are the data and the ground truth. Nothing else is generated here.
